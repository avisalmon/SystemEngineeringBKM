מתחילים

שלושה צעדים, ואז הצ'אט מוביל

לא צריך לדעת git, Python או תכנות. צריך מחשב, עורך עם צ'אט AI ועשר דקות. את כל השאר הצ'אט מסביר, מתקין או מראה איך.

לפני שמתחילים: שלושה דברים במחשב

  • VS Code, העורך. הורדה חינמית מ-code.visualstudio.com.
  • Git, שמוריד את המאגר ומעדכן אותו. הורדה מ-git-scm.com, ובהתקנה מאשרים את ברירות המחדל.
  • צ'אט AI אחד בתוך העורך: GitHub Copilot במצב Agent, או Claude Code. אפשר גם Cursor במקום VS Code.

כותבים בצ'אט "שלום" ומקבלים תשובה.

1

משכפלים את המאגר, בלחיצות

  1. ב-VS Code לוחצים Ctrl+Shift+P, כותבים Git: Clone ובוחרים בו.
  2. מדביקים את הכתובת הזו ולוחצים Enter:
https://github.com/avisalmon/SystemEngineeringBKM.git
  1. בוחרים תיקייה, למשל C:\se, וכשהעורך שואל לוחצים Open.
  2. אם העורך שואל אם לסמוך על המחברים, לוחצים "Yes, I trust the authors".

בסרגל הקבצים של העורך רואים את התיקייה SystemEngineeringBKM.

מעדיפים טרמינל?

מה זה טרמינל?

חלון שבו כותבים פקודות למחשב במקום ללחוץ על כפתורים. ב-VS Code פותחים אותו מהתפריט Terminal ואז New Terminal. כך נראית שורת הפקודה:

PS C:\Users\you>

מעתיקים את ארבע השורות, מדביקים בטרמינל ולוחצים Enter. השורה האחרונה פותחת את המאגר בעורך.

mkdir C:\se
cd C:\se
git clone https://github.com/avisalmon/SystemEngineeringBKM.git
code SystemEngineeringBKM
2

פותחים את הצ'אט

  • GitHub Copilot ב-VS Code: לוחצים Ctrl+Alt+I, ובתחתית החלון בוחרים במצב Agent.
  • Claude Code: פותחים טרמינל בתיקיית המאגר וכותבים claude.
  • Cursor: לוחצים Ctrl+L.

הצ'אט פתוח, והתיקייה SystemEngineeringBKM פתוחה בעורך.

3

כותבים בצ'אט:

מה אני עושה פה?

מכאן הצ'אט מוביל: מסביר מה יש כאן, בודק מה מותקן, מתקין את מה שחסר, ופותח איתכם פרויקט חדש או ממשיך פרויקט קיים.

אין פקודות להקליד. כשהצ'אט צריך להריץ משהו, הוא מציג את הפקודה ומבקש אישור. לוחצים Allow או Run, ואם משהו לא ברור, שואלים אותו "מה זה עושה?".
המסע

מהצורך ועד הקונספט הנבחר, בתשעה שלבים

כל שלב נגמר במשהו שאפשר לראות ולהציג. השיטה איטרטיבית, אז אפשר לחזור לשלב קודם, ובכל שער נשמרת תמונת מצב של הפרויקט (baseline). השלבים 2 עד 8 צמודים לשלבי ICDM ולמפגשי הקורס.

השיטה והתקנים

שיטת ICDM, בשפה של התקנים

השיטה היא ICDM ותהליך QRD של ד"ר עמיהוד הרי, שנבחנו בתעשייה הישראלית. התקנים נותנים את השמות, את הסקירות ואת צורת המסמכים שלקוחות ותוכניות ביטחוניות מצפים להם.

תקןמה הוא נותן כאן
ISO/IEC/IEEE 15288תהליכי מחזור החיים של המערכת.
ISO/IEC/IEEE 29148 ומדריך הכתיבה של INCOSEאיך כותבים דרישות טובות ואיך בודקים אותן.
ISO/IEC/IEEE 42010מבטים על הארכיטקטורה.
ISO/IEC/IEEE 24748-7 ו-24748-8הנדסת מערכות בתוכניות ביטחוניות, וסקירות טכניות כמו SRR, SFR ו-PDR.
MIL-STD-498 ו-MIL-STD-961צורת המסמכים (OCD, SSS, IRS) ומבנה מפרט.

שלושה אופני חשיבה, בו בזמן

בשלבי התכן המושגי עובדים בשלושה אופנים יחד, ושניים מהם נוטים לקלקל זה את זה: ככל שחושבים יותר אנליטית, היצירתיות נחלשת. בכל שלב הצ'אט אומר באיזה אופן עובדים.

כמותי ומסודר: לכתוב את כל הדרישות, לכתוב אותן נכון ולא לשכוח אף אחת.

אדום: יצירתי

להמציא עקרונות פתרון וקונספטים, הרבה ושונים זה מזה.

ירוק: אנליטי
